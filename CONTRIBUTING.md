# Contributing to Git for Prompts

First off, thank you for considering contributing to Git for Prompts! It's people like you who make it a great tool for everyone.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct.

## How Can I Contribute?

### Reporting Bugs

- Check if the bug has already been reported in the **Issues** tab.
- If not, create a new issue with a clear title and description, including steps to reproduce.

### Suggesting Enhancements

- Open a new issue with the tag `enhancement`.
- Describe the feature you'd like to see and why it would be useful.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints (`npm run lint`).
6. Submit a pull request!

## Development Setup

See the [README.md](README.md) for detailed setup instructions.

## Style Guide

- Use TypeScript for all new code.
- Follow the existing code style (2-space indentation, semicolons, etc.).
- Use descriptive commit messages.

Thank you for your contributions!
