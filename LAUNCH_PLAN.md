# Git for Prompts — Twitter/X Launch Video Plan & Script

## Overview
- **Goal**: 25-Second high-converting product demo video for X/Twitter launch.
- **Format**: Screen Recording + Text Overlays + Background Synth/Lo-Fi Beat (No voiceover needed).
- **Focus Split**: 50% Terminal CLI + 50% Web Dashboard UI.

---

## 🎬 25-Second Shot-by-Shot Storyboard

### Shot 1 (0s – 4s): The Hook — Terminal CLI Init
- **Screen**: Clean dark terminal.
- **Action**: Type `$ npx gfp init` and hit enter. Show local `.gfp/` directory and prompt files populating instantly.
- **Text Overlay**: `"Stop managing AI system prompts in Google Docs or random text files."`

### Shot 2 (4s – 10s): The CLI Publish
- **Screen**: Terminal editor showing prompt file (`prompt: "You are a code reviewer..."`).
- **Action**: Type `$ npx gfp publish v2` → terminal outputs `✔ Published version v2`.
- **Text Overlay**: `"Git for Prompts treats your LLM prompts like production code."`

### Shot 3 (10s – 17s): The Web UI Version Diff Engine
- **Screen**: Cut smoothly to `https://gitforprompts.vercel.app/dashboard`.
- **Action**: Click repository `code-reviewer-pro` → open **Version History / Diff tab**.
- **Visual**: Show side-by-side green/red prompt diff (red old prompt vs emerald green updated prompt).
- **Text Overlay**: `"Visual diffs, version history, & automatic rollback."`

### Shot 4 (17s – 22s): Test Suite & Pass Rates
- **Screen**: Web UI **Test Runner / Eval** tab.
- **Action**: Click `Run Test Suite` button → show test cases running with green pass badges (`98% Pass Rate`).
- **Text Overlay**: `"Run test suites against GPT-4o, Claude 3.5, & Gemini before deploying."`

### Shot 5 (22s – 25s): Outro & Call to Action
- **Screen**: Dark background with dark rounded Git for Prompts logo tile + hero headline.
- **Text on Screen**:
  ```text
  Git for Prompts
  Local-First Prompt Version Control for AI Engineering
  Try it free: gitforprompts.vercel.app
  ```

---

## 🛠️ Recording Setup & Editing Checklist

1. **Browser**: Chrome/Arc at 125% zoom (crisp on mobile). Hide bookmarks & extra tabs.
2. **Terminal**: Dark theme, font size 16px, line height 1.4.
3. **Screen Recorder**: Record at 1080p/4K at 60fps.
4. **Editing**: Trim typing pauses, speed up terminal execution to 1.25x–1.5x, add click sound effects + minimal background synth beat.
